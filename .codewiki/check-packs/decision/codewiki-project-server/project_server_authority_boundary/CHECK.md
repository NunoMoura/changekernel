# Project Server authority boundary

## Requirement

The exact Decision Candidate must preserve Project Server as sole project authority; keep Runtime, DSH, Broker Host, Domain Plugins, Clients, Harnesses, and Checks within their admitted custody; and introduce no mutable self-loading or repository-local executable authority.

## Pass

Pass only when proposed meaning preserves every affected CodeWiki authority, custody, provenance, and execution boundary.

## Fail

Fail when meaning transfers authority, conflates controller and subject, permits mutable self-loading, or leaves ownership ambiguous.
