# Project Server change coverage

## Requirement

The exact Planning Candidate must cover every affected Knowledge, protocol, schema, migration, source, test, package, external qualification, recovery, and cleanup obligation while keeping controller release and governed subject identities distinct.

## Pass

Pass only when all affected CodeWiki ownership, migration, compatibility, qualification, and cleanup surfaces have explicit bounded work.

## Fail

Fail when a required surface is omitted, merged across authority boundaries, left unverifiable, or assigned to the wrong owner.

## Feedback

Identify exact omitted surface, owning Component, and Work Unit or dependency requiring correction.
