# Project Server aggregate integrity

## Requirement

The exact integrated aggregate must preserve fixed CodeWiki authority and custody boundaries, prove complete cross-unit realization, and include every packed, external, recovery, containment, provider, lifecycle, and cleanup artifact required by the accepted Change scope.

## Pass

Pass only when aggregate bytes, lineage, and admitted Evidence prove all scope-applicable CodeWiki architecture and release obligations.

## Fail

Fail when any boundary drifts, aggregate obligation is incomplete, or required external evidence is missing, stale, self-authored, or bound to another tree.

## Feedback

Identify exact aggregate obligation, Evidence digest, affected Work Unit, and correct Project Server-owned feedback route.
