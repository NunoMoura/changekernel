# Review

Review is the final stage for a Committed Change that required project realization. True Wiki-only Changes complete in their Change Commit and do not enter Review. Review judges whether one exact reconciled full Project snapshot realizes the committed Wiki target without introducing uncommitted meaning.

Review is whole-Change verification before local completion, not a software-specific meeting or deployment approval. Individually valid report sections can still contradict one another or omit the accepted research question. A Review finding therefore need not imply that differently scoped Implementation Checks ran incorrectly. Prior Results cannot be transplanted into Review; reuse requires exact declared bindings and governing policy rather than repeated ceremony or assumed equivalence.

Review starts only after every current Work Unit has a passing Implementation Gate, integrates onto the managed Change ref, and satisfies dependency closure. Before Review, the managed Change tip must incorporate the current canonical Project head into one exact prospective Completion project-artifact tree. If canonical history advanced, Project Server creates an explicit reconciliation attempt on the Change ref, preserving admitted lineage and applying the Change artifact delta to that head. Conflict, overlap ambiguity, or invalidated Work stops for explicit repair; changed artifact bytes invalidate affected Results and require fresh Checks. No silent semantic merge occurs. The Review subject is this exact reconciled Change tip/tree plus its unchanged expected canonical parent, Change Commit, committed Wiki delta or existing-Wiki targets, planning facts, contributing Work Unit commits, Check Results, and Evidence. A provider pull request may mirror this lineage but is neither required transport nor authority.

A Review Agent runs through a fresh bounded DSH Run with exact relevant Wiki inputs and read-only tools. Project Server resolves exact Review Check Packs and freezes active Checks from Change type and subject. Explicitly adopted Checks may cover complete target realization, cross-unit consistency, integration, provenance, scope, and applicable security/compatibility policy; software builds and behavior are domain-specific cases. Human review may enter as authenticated Evidence when active Checks require it.

Review does not reconsider or silently edit Committed Change intent. A Work Unit defect returns to exact affected implementation. A decomposition defect returns to Planning amendment. A meaning or type defect requires a Superseding Change through Decision. Out-of-scope findings enter Change Intake. Every route preserves exact Results and responsibility; no Check or model chooses lifecycle authority.

A failed Gate leaves the Change committed and incomplete. A stopped Gate preserves state and exposes recovery. A passed Gate qualifies only the exact reconciled Change tip and prospective Completion project-artifact tree. Project Server revalidates the Gate, Change Commit, Work Units, current Change tip, exact reviewed tree, unchanged canonical head, authority, and relevant active-Change conflicts before creating the Change Completion Commit by expected-head CAS. Canonical-head drift restarts reconciliation and affected Review; it cannot reuse the prior Gate.

The Completion Commit joins the unchanged reviewed canonical parent to the exact reconciled Change tip and preserves every reviewed project-artifact entry and OID. Its only permitted full-tree difference from the reviewed tip is the mechanically constructed bounded `change.completed` append to that Change's Trace. Kernel validation binds the exact prior Trace, Review Gate, operation bytes, and resulting Trace blob before CAS; the operation uses the fixed containing-commit marker rather than embedding its own commit OID. Git first-parent history remains canonical Project state; second-parent ancestry preserves complete Change collaboration. Delivery, publication, remote push, and external outcomes are later separately authorized effects and observations, not implicit Review or local completion.
