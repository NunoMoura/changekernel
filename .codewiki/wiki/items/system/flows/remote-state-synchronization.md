# Remote State Synchronization

Git natively preserves/transports exact objects and refs. Remote hosting/delivery integrations are optional; they do not define semantic acceptance or make native history depend on an external data connector. Host UI records do not automatically travel in clones.

Bind remote observations to exact subjects and scope. Cached refs, timestamps, merge flags and check conclusions are not acceptance. Assess the actual combined candidate, not an isolated prior head.

Preserve portable Change grounds, judgments and required object reachability. Notes and rewritten history need explicit transport/retention handling. Missing history cannot be regenerated by a model.

Publication and external effects require authority before execution. Distinguish their observed outcomes from local acceptance and realization; reconcile unknown effects before retry. Reads do not silently repair local semantic state.
