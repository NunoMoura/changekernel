The exact Work Unit Candidate must realize every assigned Knowledge Effect and acceptance requirement, include proportionate source and test Evidence, preserve dependency outputs, and contain no undeclared scope.

Pass only when Candidate bytes and admitted Evidence prove complete, scoped realization of the exact Work Unit.

Fail when realization, tests, Evidence, dependency bindings, or scope discipline are incomplete or contradictory.
