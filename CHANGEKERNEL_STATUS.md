### Findings and accepted boundaries

**A1 — Native permission safety.** Submitted `restart-host-contract/CHANGEKERNEL_STATUS.md:11–13` treats empty supplementary groups as a narrower user context. Linux group permission selection is not monotonic: for a file owned by another UID, group `G`, mode `0604`, a user in supplementary `G` is denied by the group bits; dropping `G` selects readable `other` bits. A similar problem applies to ancestor search and ACL matching. [Linux user namespaces](https://man7.org/linux/man-pages/man7/user_namespaces.7.html), [path permission selection](https://man7.org/linux/man-pages/man7/path_resolution.7.html) and [ACL access checks](https://man7.org/linux/man-pages/man5/acl.5.html#ACCESS_CHECK_ALGORITHM) document the behavior. Preserve primary-GID accuracy, but require faithful acting-user authorization plus independently narrower restrictions, or a proven supported intersection. This is a correctness repair before the user can choose deployment costs, not permission to approve broader native rights as a convenience.

**A2 — Closed control inventory.** Submitted lines 29–41 name root registry, slot inventory, policy/revocation guard, root-entry descriptor and provisioning interlock without closing which are directory authority, persisted controls, immutable deployment inputs or live guards. Request one finite inventory, exact authority/absence/capacity meaning and explicit remaining gates. Do not require a new manifest or DB by fiat. Conditional single-writer observation, permanent slots and private preparation before activation remain useful; the whole A codec/host is not accepted.

Historical delivery, failure scope and original-result/current-readiness separation are retained as conditional obligations; no protocol is adopted.
