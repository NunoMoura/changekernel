# Qualification and Benchmarks

Qualification evaluates a declared execution profile on exact immutable candidate bytes. Native tests, structural checks, replay and injected runners supply bounded engineering evidence, not proof of operational semantic quality, custody or continuation.

The first local dogfood qualification is the bounded loop in the [release contract](package.md#minimum-local-dogfood), not completion of every benchmark scenario. Broader product evaluation should exercise software and non-software Changes, consequential contradiction/uncertainty followed by inquiry or repair, shared Planning obligations, conflicting parallel work and fresh-context recovery. Test original reasons still holding, one failed assumption with independent support, and a rejected alternative becoming appropriate.

The core loop and historical retrieval must work with zero external data connectors. Exercise promotion, retirement and re-adoption boundaries: reading an old rule, moving a file, generating a RAG answer or evicting context cannot silently change authority. Missing historical objects, private inputs and unavailable evidence must remain honest limitations.

Compare quality and effort with a well-written prose/Git baseline. Measure consequential omissions, false acceptance, unnecessary rejection, repeated inquiry/effects, context loss, resource use and human intervention. More metadata, sources or retrieved text is not inherently better. For delegation experiments, count the main session and all workers, handoffs, review, repair and validation; compare total cost, elapsed time and accepted quality with direct work. A lower worker token price or a completed subagent run is not evidence of savings.

Qualify the actual Check definition, model/runtime and bounded input profile, including private/local execution without remote fallback. Measure first actionable feedback, total tokens/cost/time through repair rounds, false activation, cache reuse/invalidation and fresh-session reconstruction. Include denied extension writes, network and credential access, exhausted budgets, missing inputs, source instruction attacks and unchanged retries that must not become a pass lottery. A smaller model or Pack signature is not semantic qualification.

Freeze corpus, environment, supported capabilities, resource/time/output and token/cost/retry limits and quality thresholds before testing. Binding failures cannot be averaged away. Use the [immutable release boundary](package.md); real-world outcomes need observations beyond committed documents.
